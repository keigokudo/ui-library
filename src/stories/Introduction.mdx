# Portfolio / C2 UI foundation

This Storybook is the visual-development environment for `@krnjs/react-ui`.

The previous component experiments have been removed. The package intentionally
has no public UI components while the Portfolio / C2 design direction is being
established.

Future components should be added only when their API and visual direction are
defined. Component stories, interaction checks, and accessibility checks should
live alongside each implementation.
